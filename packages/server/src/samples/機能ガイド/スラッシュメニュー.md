# スラッシュメニュー

本文で `/` を打つと挿入候補が出ます。行頭でも、文の途中(空白の直後)でも出ます。

| キー | 動作 |
| --- | --- |
| ↑ / ↓ | 候補を選ぶ |
| Enter / Tab | 挿入する |
| Escape | 閉じる |

`/` と打った文字は挿入時に消えるので、本文に痕跡は残りません(直前の空白も一緒に消します)。

## 候補

| 候補 | 入るもの |
| --- | --- |
| 見出し 1 / 2 / 3 | `#` / `##` / `###` |
| 箇条書き | `- ` |
| 番号付きリスト | `1. ` |
| チェックボックス | `- [ ] ` |
| 引用 | `> ` |
| コードブロック | ` ``` ` |
| 表 | 3 列 2 行の GFM テーブル |
| 区切り線 | `---` |
| ノートへのリンク | `[[` を置いてノート名の補完へ引き継ぎます |
| タグ | `#` を置いてタグの補完へ引き継ぎます |

**入るのは標準 Markdown に往復できるものだけ**です。独自ブロックは足しません(他のエディタで開いても壊れないため)。

## 探し方

日本語・かな読み・英語・記法そのもの、どれでも引けます。

- `/見出し` `/みだし` `/heading` `/##` → 見出し
- `/表` `/ひょう` `/table` → 表

日本語入力(IME)で変換中の Enter は変換の確定に使われ、候補の確定には取られません。

## パスは誤爆しません

`foo/bar` のように**文字の直後**に来る `/` ではメニューは出ません。行頭か空白の直後だけが対象です。
