# スラッシュメニュー

本文で `/` を打つと挿入候補が出ます。行頭でも、文の途中(空白の直後)でも出ます。

| キー | 動作 |
| --- | --- |
| ↑ / ↓ | 候補を選ぶ |
| Enter / Tab | 挿入する |
| Escape | 閉じる |

`/` と打った文字は挿入時に消えるので、本文に痕跡は残りません(直前の空白も一緒に消します)。

## いる場所で並びが変わる

候補の並びは**いまカーソルがどこに居るか**で変わります。消えるものはありません — **順番が変わるだけ**です(タスクの行から表を作りたいこともあるので)。

| いる場所 | 上に来るもの |
| --- | --- |
| タスクの行(`- [ ]`) | タスクの状態 / 優先度 / 期限 |
| リストの中 | 箇条書き / 番号付きリスト / チェックボックス |
| 表のセル | 表 |
| 何も書いていない行 | 見出し・リスト・引用・コード・表など、ブロックを作るもの |
| 文の途中 | リンク・タグ・数式のような、どこでも使えるもの |

同じ強さの候補どうしは並びが固定なので、「いつもの位置」で覚えられます。

## 候補

| 候補 | 入るもの |
| --- | --- |
| 見出し 1 / 2 / 3 | `#` / `##` / `###` |
| 箇条書き | `- ` |
| 番号付きリスト | `1. ` |
| チェックボックス | `- [ ] ` |
| タスクの状態 / 優先度 / 期限 | `[status:: todo]` / `[priority:: medium]` / `[due:: 今日]` |
| 引用 | `> ` |
| コードブロック | ` ``` ` |
| 表 | 3 列 2 行の GFM テーブル |
| 区切り線 | `---` |
| ノートへのリンク | `[[` を置いてノート名の補完へ引き継ぎます |
| タグ | `#` を置いてタグの補完へ引き継ぎます |
| インラインコード | `` `コード` `` (中身は選択済みなので、そのまま打てば置き換わります) |
| 今日の日付 | `2026-01-01` (ジャーナルのファイル名と同じ書き方) |

**入るのは標準 Markdown に往復できるものだけ**です。独自ブロックは足しません(他のエディタで開いても壊れないため)。

## 探し方

日本語・かな読み・英語・記法そのもの、どれでも引けます。

- `/見出し` `/みだし` `/heading` `/##` → 見出し
- `/表` `/ひょう` `/table` → 表

日本語入力(IME)で変換中の Enter は変換の確定に使われ、候補の確定には取られません。

## パスは誤爆しません

`foo/bar` のように**文字の直後**に来る `/` ではメニューは出ません。行頭か空白の直後だけが対象です。


## 選択したテキストを変える

文字を選ぶと、その上に小さなツールバーが浮かびます。

| ボタン | 変換 |
| --- | --- |
| `**` | 太字 |
| `*` | 斜体 |
| `` ` `` | インラインコード |
| `~~` | 取り消し線 |
| `[[]]` | 選択した文字をノートへのリンクにする |

もう一度押すと外れます。**モバイルではキーボードショートカットが使えない**ので、選択したテキストを変える入口はこのツールバーです。

出るのは往復できる記法だけです(装飾のためのボタンは置きません)。

## 絵文字

半角の `:` を打つと絵文字の候補が出ます。`:rocket` → 🚀、`:おめでとう` → 🎉(よく使うものは日本語でも引けます)。

- **入るのは絵文字そのもの**です。`:rocket:` のようなショートコードはファイルに残りません
- 日本語入力中の全角 `：` では出ません(英数入力のときだけ)
- `12:30` や `https://` のように**文字の直後**に来る `:` でも出ません

## 補完どうしの優先順

`[[` / `#` / `/` / `:` は条件が重ならないように作ってありますが、万一重なったときに開くのは **1 つだけ**です。順番はスラッシュ → ノートのリンク → タグ → 絵文字。「なぜか候補が出ない」が起きないよう、優先順は各機能が明示的に宣言しています。
