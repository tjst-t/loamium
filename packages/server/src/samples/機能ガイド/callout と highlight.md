# callout と highlight

どちらも **Obsidian の書き方そのまま**です。独自記法は足していないので、他のエディタで開いてもただの引用とテキストとして読めます。

## callout (注記)

引用の 1 行目を `[!種別]` で始めると注記になります。

> [!note] メモ
> 1 行目がタイトル、2 行目からが本文です。

> [!warning] 注意
> 種別は縁の色とラベルで示します。

使える種別: `note` / `tip` / `info` / `warning` / `danger` / `quote` / `example`。知らない種別はただの引用のままです。

`/callout` から挿入できます(タイトルが選択された状態で入るので、そのまま打てば置き換わります)。

## ハイライト

`==囲んだ部分==` が ==ハイライト== になります。

- 選択して、浮かぶツールバーの `==` を押しても付けられます(もう一度押すと外れます)
- `/ハイライト` から挿入もできます
- **カーソルがそのハイライトに入ると `==` がそのまま出ます**。編集するときは本物の記法を相手にできます

> [!tip] ファイルはそのまま
> どちらも表示だけの仕組みで、保存される Markdown は書いたとおりです。
> 行頭の `==強調==` に backslash が付かないことも確認しています。
