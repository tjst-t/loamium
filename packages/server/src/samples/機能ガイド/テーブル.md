# テーブル

標準の Markdown テーブル(GFM)がそのまま使えます。書き込まれるのは普通の `|` 記法だけで、独自記法は一切ありません。

| 名前 | 役割 | 状態 |
| --- | --- | --- |
| メモ | 素材 | 進行 |
| ノート | 成果 | 完了 |

## セルを移動する

- **Tab / Shift+Tab** で次/前のセルへ。行末の Tab は次の行へ移ります
- 矢印キーとクリックはそのまま使えます

## 行と列を足す・消す・動かす

セルにカーソルを入れると、**表の右上に操作バー**が出ます。

| ボタン | すること |
| --- | --- |
| `行 +` / `行 −` | カーソルのある行の下に追加 / その行を削除 |
| `行 ↑` / `行 ↓` | 行を上/下へ動かす |
| `列 +` / `列 −` | カーソルのある列の右に追加 / その列を削除 |
| `列 ←` / `列 →` | 列を左/右へ動かす |
| `表を削除` | 表ごと消す |

押せない操作は薄く出ます(端の行を外へ動かす、1 列しかない表の列を消す、など)。

> [!note] 見出し行は消せません
> GFM のテーブルは見出し行が必須なので、見出し行の削除と移動は塞いであります。表そのものを消したいときは `表を削除` を使ってください。

## 揃え(アライメント)

区切り行の `:` で列の揃えを指定できます。指定していない列は `| - |` のまま保たれます。

| 左揃え | 中央 | 右揃え |
| :--- | :---: | ---: |
| left | center | right |
| ひだり | まんなか | みぎ |

## ポイント

- 保存されるのは常に**正規形の標準 Markdown テーブル**です(`make roundtrip` の gate と同じ形)
- 新しい表は [[スラッシュメニュー]] の `/表` で入ります
- 生の `|` を直接直したいときは、右上の `.md` でソースモードに切り替えられます
