# コードフェンス

言語名を付けたコードフェンスは色が付きます。

```ts
const greet = (name: string): string => `こんにちは ${name}`
// コメント
```

- 対応: TypeScript / JavaScript / JSX / TSX / JSON / YAML / bash / Python / Go / Rust / SQL / CSS / HTML / Markdown / diff
- `ts` `js` `sh` `yml` `py` `rs` `md` などの短い書き方も通ります
- 言語名が無いフェンスは色を付けません
- 配色はこのアプリのインクとアクセントに合わせています(外のテーマは読み込みません)

`/コードブロック` からも挿入できます。

## 特別な言語

| 言語 | 何が起きるか |
| --- | --- |
| `mermaid` | 図として描画します([[mermaid 図]]) |

ファイルに書かれるのはいつものコードフェンスのままです。
