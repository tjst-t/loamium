# ブックマーク

よく開くノートに ★ を付けておけます。エディタ上部のバーの ★ を押すだけです。

## どこに保存されるか

ノート自身の frontmatter です([[プロパティ]]の一種)。

```
---
bookmark: true
---
```

設定ファイルの一覧ではないので、**ノートと一緒に旅をします**。vault を別の場所へ移しても、アプリのキャッシュを全部消しても残りますし、Obsidian や素のエディタで開いてもただの YAML として読めます。

★ を外すと `bookmark: false` を残さず、キーごと消えます(意味のない行をノートに溜めないため)。

## 一覧

左のサイドバーの「ブックマーク」に、★ の付いたノートが並びます(`title:` があればそれを、無ければファイル名を出します)。1 件も無いときは区画ごと出ません。

## エージェントから

- `list_bookmarks` — ★ の付いたノート一覧
- `set_bookmark` — 付け外し(`bookmark: false` で外す)
