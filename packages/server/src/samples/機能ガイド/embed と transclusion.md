# 埋め込み (transclusion)

`![[ノート名]]` と書くと、そのノートの中身をその場に表示します。`![[ノート名#見出し]]` なら、その見出しの節だけを表示します。

![[プロジェクト Hydra#目的]]

## 決まりごと

- **正本は埋め込み元のファイル**です。ここに表示されている中身は読むためのもので、直したいときは見出しをクリックして元のノートを開きます
- 解決の規則は `[[リンク]]` と同じです([[wikilink とバックリンク]] を参照)
- 長い節は途中まで表示します
- 行き先が無いときは赤く出ます

## ファイルに書かれるもの

本文に残るのは `![[ノート名#見出し]]` という文字列だけです。カードは表示のために足しているもので、保存される Markdown は書いたとおりです。カーソルを記法の中に置くと、そのまま `![[…]]` が出ます。

エージェントからは `read_embed` で同じ解決規則で中身を読めます。
