# タグと詳細検索

## タグの書き方

タグは本文中の `#タグ` と frontmatter の `tags:` の両方から集めます。標準 Markdown のままです。

- `#仕事` — 本文中のインラインタグ
- `#読書/SF` — `/` で入れ子にできます。`#読書` で絞ると子タグのノートも含まれます
- frontmatter は 3 通りの書き方を読みます

```yaml
---
tags: [仕事, 読書]
---
```

### タグにならないもの

| 書き方 | 理由 |
| --- | --- |
| `# 見出し` | `#` の後ろに空白がある |
| `https://example.com/#section` | 直前が英数字(URL のフラグメント) |
| `#1` | 数字だけ |
| `` `#コード` `` / コードフェンス | コードの中 |

日本語の書き方に合わせて、`。#タグ` のように句読点の直後に書いたものは拾います。

## タグの入力補完

本文で `#` を打つと、vault で使われているタグの候補が出ます。↑ ↓ で選び、Enter か Tab で確定、Escape で閉じます。

## タグをクリックすると絞り込み

エディタ上のタグをクリックすると、そのタグで絞り込んだ詳細検索ページが開きます。

## 詳細検索ページ

`Ctrl+Shift+F`(左サイドバーの「詳細検索」ボタンでも同じ)で開きます。

- **検索語** — ノート名と本文を横断する部分一致。大小文字・全角半角のゆれは吸収します
- **タグ** — タグをクリックして絞り込み。もう一度押すと外れます
- **フォルダ** — そのフォルダ配下だけに絞ります
- 検索語を空にして、タグやフォルダだけで一覧することもできます

条件は URL に載ります(`?q=…&tag=…&folder=…`)。ブックマークや共有ができ、結果からノートを開いたあと**戻る**と条件がそのまま復元されます。

結果はノートごとにまとまり、行番号つきで並びます。行をクリックするとその箇所までスクロールして開きます。

> Ctrl+K のパレットは「思い出したノートへ飛ぶ」ため、詳細検索は「条件で絞って見渡す」ためのものです。
