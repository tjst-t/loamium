# ナビゲーションとツリー操作

開いているノートは **URL に載ります**。ブラウザの戻る/進む、リロード、ブックマーク、URL の共有がそのまま効きます。

## URL と戻る/進む

| 状態 | URL |
| --- | --- |
| ノートを開いている | `?path=フォルダ/ノート名.md` |
| 何も開いていない | `?path=` なし |

- ノートを開くたびに履歴へ積まれるので、**戻る/進むがノートの行き来**になります
- 同じノートを続けて開いても履歴は積みません(戻るが効かなくなるのを防ぐため)
- URL を直接開く/リロードすると、そのノートに直接着地します
- 起動時に `?path=` が無ければ、その日のジャーナルへ着地します(履歴には積みません)
- リネーム・移動・削除に追従します(履歴は置き換えるので、戻って消えたパスに着地することはありません)

## 表示位置とカーソルの復元

ノート A を読んでいる途中で B へ移り、**戻ると A の同じ位置・同じカーソル**に戻ります。

- 復元してもフォーカスは奪いません(ツリーやパレットの操作を続けられます)。エディタに入った時点でカーソルがその位置に置かれます
- 憶えているのはメモリの中だけです。**ファイルには一切書きません**(どこを見ていたかは文書の一部ではないため)。リロードすると忘れます

## ESC

`Escape` は「外側へ一段ずつ抜ける」キーです。

1. リスト・引用・コードブロックの中にいるなら、そのノードを抜けて素の段落へ
2. 抜ける先が無ければ、選択を解除してエディタから抜けます(blur)

## 右サイドバー(情報パネル)

右端のボタンで開閉します。開閉の状態は憶えているので、閉じておけば次も閉じたままです。

- いまは開いているノートのパス・文字数・行数を表示します
- 画面が狭いとき(モバイル)は画面を左右に割らず、**下からのシートとして開きます**。右下の丸ボタンで開閉します

## ツリー

左サイドバーのフォルダツリーからノートを辿ります。フォルダ行のクリックで開閉、行の `…` から作成・リネーム・移動・削除ができます(詳しくはツリー上の操作メニューを参照)。

## 検索

`Ctrl+K`(macOS は `Cmd+K`)で検索パレットが開きます。選ぶとノートを開き、一致箇所まで自動でスクロールします。
