# プロパティ (frontmatter)

ノートの先頭を `---` で挟んだ YAML が**プロパティ**です。標準の frontmatter そのもので、独自記法はありません。Obsidian や素のエディタで開いても、ただの YAML として読めます。

```
---
title: 走り書き
created: 2026-08-23
done: false
count: 3
tags:
  - 仕事
---
```

## どこで編集するか

**本文の中には出しません。**右の情報パネルの「プロパティ」で、型に合った入力欄から編集します(frontmatter はデータモデルであって本文ではない、という考え方です)。

- キー名をクリックして書き換え → Enter か、フォーカスを外すと確定
- 右の型セレクタで意味型を変える(値も型に合わせて書き直されます)
- `×` でそのキーを削除
- 一番下の「プロパティを追加」でキーを先に決めて追加。vault で既に使われているキーは候補に出ます

## 型

| 型 | 書かれ方 |
| --- | --- |
| テキスト | `title: 走り書き` |
| 数値 | `count: 3` |
| 日付 | `created: 2026-08-23` |
| 真偽 | `done: false` |
| リスト | `links:` + `  - a` |
| タグ | `tags:` + `  - 仕事`(キー名が `tags` なら自動でこの型) |

タグはインラインの `#タグ` と合流して [[タグと詳細検索]] から辿れます。

## 書き換えの作法

> [!note] 1 キーずつしか書きません
> 保存はプロパティ 1 つずつ行われ、**ノート全体を上書きしません**。触っていない行・コメント・並び順はそのまま残るので、git の diff は変えた 1 行だけになります。外部エディタやエージェントが同時に別のキーを足していても、それを巻き戻しません。

## エージェントから

- `list_property_keys` — vault で使われているキー(使用数つき)
- `get_properties` — そのノートのプロパティ
- `set_property` / `remove_property` — 1 キーずつ書き換える
