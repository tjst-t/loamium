# スマートフォルダ

「条件で集まるフォルダ」です。左のサイドバーの **スマートフォルダ** に並び、押すと当てはまるノートが一覧されます。

## 中身は保存したクエリ

条件は [[dataview の使い方]] と**同じクエリ文字列**です。仕組みを 2 つ持たないので、本文に書いたクエリで試してから、そのままスマートフォルダにできます。

定義は vault の `smart-folders/<id>.yaml` に置かれます。

```yaml
id: todos
name: 未完了TODO
icon: flame
query: LIST WHERE file.open_tasks SORT file.mtime DESC
order: 3
```

アプリの設定ファイルではないので、vault を別の場所へ移してもキャッシュを消しても残ります。

## 作る・直す・消す

- サイドバーの見出しの **+** から、名前とクエリを入れて保存
- 開いた画面の **条件を直す** で書き換え、**削除** で消せます(**ノートは消えません**)
- **書き方が違うクエリは保存できません。**その場で理由が出ます(あとで「なぜか 0 件」になるより、いま断る)

## 便利な組み込み

| 書き方 | 集まるもの |
| --- | --- |
| `LIST WHERE file.open_tasks` | やり残しのタスクがあるノート |
| `LIST WHERE bookmark` | ★ を付けたノート([[ブックマーク]]) |
| `LIST FROM "日誌" SORT file.name DESC LIMIT 7` | 最近のジャーナル |
| `TASK WHERE priority = "high"` | 優先度の高いタスク([[タスク]]) |

## エージェントから

- `list_smart_folders` — 一覧
- `run_smart_folder` — そのフォルダのクエリを走らせる
- `save_smart_folder` / `delete_smart_folder` — 作る・書き換える・消す
