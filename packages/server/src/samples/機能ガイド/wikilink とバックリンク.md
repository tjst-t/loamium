# wikilink とバックリンク

`[[ノート名]]` でノート同士をリンクできます。`[[` と入力するとオートコンプリートが開きます。

## 基本

- 通常のリンク: [[index]]
- 表示名を変える(エイリアス): [[index|サンプル索引へ]]
- 見出しへのリンク: [[dataview の使い方#TASK — チェックボックスを横断で集める]]

## 壊れリンク

存在しないノートへのリンクは赤い破線で表示されます: [[まだ存在しないノート]]
クリックするとその名前で新規ノートを作成します。

## バックリンク

右サイドバーの「バックリンク」タブに、**このノートへリンクしている参照元**が文脈付きで表示されます。
このサンプル集では [[index]] など多くのノートが相互にリンクしているので、いろいろなノートで確認してみてください。

## リネーム追従

ノートをリネームすると、vault 全体の `[[旧名]]`(`[[旧名#見出し]]` / `[[旧名|別名]]` を含む)が自動で書き換わります。コードフェンス内は変更されません。

## 標準 Markdown リンクと URL の自動リンク

`[[ノート名]]` の内部リンクだけでなく、標準の Markdown リンクと裸の URL もクリックできます。

- Markdown リンク: [表示名](https://example.com/) — 本文中でも、callout / 引用 / 埋め込みカード / テーブルセルの中でもクリック可能なリンクとして描画されます。
- 裸 URL の自動リンク: `https://example.com/` のように Markdown 記法にしていない URL も自動でリンク化されます(末尾の句読点 `.` `、` や、囲み括弧 `)` は URL から除外されます)。
- 外部リンク(`http` / `https` / `mailto`)は新しいタブ(デスクトップアプリでは OS 既定ブラウザ)で開きます。相対パスの内部リンクはアプリ内でノートを開きます。

> [!tip] callout の中のリンク
> `> [!note]` などの callout 本文に書いた `[表示名](url)` や裸 URL も、そのままクリックできます。
