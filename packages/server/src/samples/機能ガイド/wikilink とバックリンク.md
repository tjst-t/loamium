# wikilink とバックリンク

`[[ノート名]]` でノート同士をリンクできます。**標準 Markdown のまま**で、ブロック ID のような独自記法は一切足しません。他のエディタで開いてもただの文字列として読めます。

## 基本

- 通常のリンク: [[index]]
- 表示名を変える(エイリアス): [[index|サンプル索引へ]]
- 見出しへのリンク: [[dataview の使い方#TASK — チェックボックスを横断で集める]]
- 同名のノートがあるとき: `[[フォルダ/ノート名]]`

クリックするとそのノートを開きます。

## 入力補完

`[[` と打つとノートの候補が出ます。

| キー | 動作 |
| --- | --- |
| ↑ / ↓ | 候補を選ぶ |
| Enter / Tab | 確定する(`]]` まで自動で閉じます) |
| Escape | 候補を閉じる |

確定すると、ノート名が vault 内で一意ならノート名だけ、重複するならフォルダ付きのパスで書き込まれます(必ず解決できる書き方になります)。

## 解決の規則

1. パスの一致 → ノート名の一致 の順に探します
2. 同名が複数あるときは**リンク元と同じフォルダ**を優先し、次に浅い階層、最後に名前順
3. 大小文字と NFC のゆれ(濁点の合成・分解)は吸収します

コードフェンスやインラインコードの中の `[[…]]` はリンクとして扱いません(`` `[[これ]]` `` はただの文字列です)。

## 壊れリンク

存在しないノートへのリンクは赤く表示されます: [[まだ存在しないノート]]

クリックするとその名前でノートを作成して開きます。置き場所はリンク元と同じフォルダです(`[[フォルダ/名前]]` と書いてあればそのパス)。

## バックリンク

右サイドバーの情報パネルに、**このノートへリンクしているノート**が行の抜粋つきで並びます。クリックすると開きます。

数え直しは毎回 vault を走査して行うので、外部エディタや git、エージェントが書き込んだ直後でも最新です。

## リネーム追従

ノートをリネーム・移動すると、vault 全体の `[[旧名]]`(`[[旧名#見出し]]` / `[[旧名|別名]]` を含む)が自動で書き換わります。

- 見出しと表示名は保たれます
- 書き方も保たれます: `[[フォルダ/ノート]]` はフォルダ付きのまま、`[[ノート]]` はノート名のまま
- コードフェンスやインラインコードの中は書き換えません
- UI からでも CLI・エージェント(`note_move`)からでも同じように追従します
