# 数式 (KaTeX)

`$…$` で文中に、`$$…$$` を独立した行に置くとブロックとして数式を書けます。

質量とエネルギーの関係は $E = mc^2$ です。

$$
\int_0^1 x^2 dx = \frac{1}{3}
$$

## 直し方

描画された数式にマウスを乗せる (モバイルはタップする) と、右上に操作バーが出ます。

- **編集** — その場で式そのものが出ます。キャレットは式の末尾に入ります
- **画像をコピー** — 描画された数式を PNG としてクリップボードへ。資料にそのまま貼れます
- **LaTeX をコピー** — 元の式のテキストをコピーします

押しただけでは編集に入りません。インラインの数式は本文に重ならないよう、操作バーが式の上に浮きます。

- インラインの式は編集中は式だけを表示します(`E = mc^2E=mc²` と並ぶと読めないため)
- ブロックの式は**式と描画を並べて**表示します。書き換えながら結果を確認できます
- 式の外をクリックすれば描画に戻ります
- `Escape` でも式から抜けられます
- 書き方が間違っているときは、消さずに赤いメッセージを出します
- `/数式` から挿入できます

## 注意

- ブロックの数式は `$$` を**独立した行**に置いてください。`$$x$$` と 1 行で書くと、保存時に `$x$` に直ります
- 文章中のドル記号(`1 ドルは $100`)は数式と紛れないよう `\$` として保存されます。表示は `$100` のままです
