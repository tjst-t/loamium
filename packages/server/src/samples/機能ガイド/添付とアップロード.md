# 添付とアップロード

画像や PDF などのファイルは、エディタへ**ドラッグ&ドロップ**するか、クリップボードから**ペースト**するだけで vault に入ります。

## 動き

1. ファイルをエディタに落とす(またはスクリーンショットを貼る)
2. `assets/` に保存され、その場に `![[assets/ファイル名]]` の段落が入る
3. 同じ名前があれば `図-2.png` のように連番が付く(黙って上書きしません)

ブラウザから画像をコピーしたときのように、クリップボードに `data:` の画像しか無い場合も、
**base64 のまま本文に埋め込まず**ファイルとして vault に出します。

書かれるのは**標準の WikiLink 埋め込みだけ**です。独自記法もメタデータも足しません。

## 表示のサンプル

このサンプル集に同梱の画像です(`![[assets/サンプル画像.png]]` と書いています):

![[assets/サンプル画像.png]]

## プレビュー

| 種類 | 見え方 |
| --- | --- |
| 画像 | そのまま表示 |
| PDF | ページを埋め込み表示 |
| CSV / TSV | 表として表示(先頭行が見出し) |
| テキスト / コード | 中身をそのまま表示 |
| その他 | ファイル名のカード(押すと開く) |

プレビューにマウスを乗せる(モバイルはタップする)と、右上に **開く** / **パスをコピー** / **削除** の操作バーが出ます。

## 消し方

- 操作バーの **削除** — 本文の `![[…]]` だけを消します(ファイルは `assets/` に残ります)
- **Backspace / Delete** — 画像の次の行の先頭で Backspace、前の行の末尾で Delete でも、埋め込みごと 1 回で消えます
- ファイルそのものを消すときは、左のツリーの `assets/` から(添付もツリーに並びます)

## 画像の大きさ

画像は**紙の幅を超えません**(原寸が大きくても、読み取り列に収まります)。

小さくしたいときは、画像にマウスを乗せると右下に出るつまみを掴んでください。**縦横比は保ったまま**幅だけが変わり、結果は

```
![[assets/図.png|420]]
```

のようにファイルへ書かれます。これは Obsidian と同じ書き方で、WikiLink の表示名の枠を使っているだけです(独自記法ではありません)。幅いっぱいまで戻すと `|420` は消えます。

## 書き方のゆらぎ

`![[assets/図.png]]` と書いても `![[図.png]]` と書いても、同じファイル名なら解決します。
`.md` を指す `![[ノート]]` はノートの埋め込み([[embed と transclusion]])で、こちらとは別物です。

## エージェントから

- `list_files` — 添付の一覧(サイズ・更新時刻)
- `read_file` — テキストの添付(txt / csv / コード)を読む
- `delete_file` — 添付を消す(ノートは `note_delete`)
