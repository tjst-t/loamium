# アウトラインとリスト

Loamium はリスト行(`- ` の箇条書き、`1. ` の番号付き、`- [ ] ` のチェックボックス)を「アウトライナー」として扱えます。すべてピュアな Markdown なので、他のエディタでもそのまま開けます。

## インデント(アウトライン操作)

- リスト行で **Tab** を押すと、その項目(と子項目のサブツリー)を 1 段深くします
- **Shift+Tab** で 1 段浅くします
- 複数行を選択して押すと、選択に含まれる全リスト項目(とその子)を一括で上げ下げします
- リストの外では Tab は何もしません(フォーカスがエディタの外へ飛ばないように握り潰します)。表の中ではセル移動が優先されます

先頭の項目は親を持てないので、Tab を押しても沈みません(CommonMark のネスト規則どおり)。

番号付きリストの採番は、インデントを変えても自動で追従します(各階層で 1 から連番、子リストは 1 から再開)。

## リスト種別の変換(箇条書き ⇄ 番号 ⇄ チェックボックス)

カーソルのあるリスト全体を、いつでも相互に変換できます。

| 変換 | ショートカット |
| --- | --- |
| 箇条書きに変換(`1. ` → `- `) | **Ctrl+Shift+8** |
| 番号付きに変換(`- ` → `1. `) | **Ctrl+Shift+7** |
| チェックボックスに変換(`- ` → `- [ ] `) | **Ctrl+Shift+9** |
| 完了 / 未完了の切り替え | **Ctrl+Shift+Enter** |

リストの外(ふつうの段落)でショートカットを押すと、その段落をリストに包みます。

チェックボックスは行頭のボックスをクリックしても切り替えられます。

## 折りたたみ

子項目を持つリスト行の左に ▸ / ▾ のトグルが出ます。クリック、または **Ctrl+.** でサブツリーを畳めます。

**折りたたみは表示だけの状態です。**ファイルには一切書き込みません(ブロック ID も独自記法も使いません)。他のエディタや git から見ても、畳んだかどうかで中身は変わりません。

## 折り返しのぶら下げインデント

リスト項目のテキストが長くて折り返すと、2 行目以降はマーカー直後のテキスト開始位置にそろいます(左端には戻りません)。ネストした項目では深さに応じてぶら下げ位置が変わります。

## ポイント

- 正本は常にピュア Markdown。保存は必ず正規形を通すので、リストマーカーや空白の揺れで差分が暴れません
- インデントは ProseMirror 標準の `sinkListItem` / `liftListItem` に乗っています
