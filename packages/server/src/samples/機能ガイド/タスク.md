# タスク

`- [ ]` / `- [x]` のチェックボックス付きリストが使えます。チェックボックスを押すと、ファイルの `[ ]` / `[x]` が書き換わります。**簡単なタスクはこれだけで完結します。**

- [x] サンプル集を vault に投入する
- [ ] [[dataview の使い方]] を読む
  - [ ] ネストしたタスクも書けます

## 状態・優先度・期限

必要なときだけ、行末に**インラインフィールド**を足せます。Obsidian Dataview と同じ `[key:: value]` の書き方で、独自記法ではありません。

- [ ] レビューを依頼する [status:: progress] [priority:: high] [due:: 2026-08-30]

画面ではピルに見えますが、ファイルに書かれているのは上のテキストそのままです。カーソルを重ねれば素の Markdown が出ます。

- **ピルを押す**と選べる値が出ます(期限は日付ピッカー)
- 挿入は [[スラッシュメニュー]] の `/状態` `/優先度` `/期限` から
- 「このフィールドを消す」でその `[key:: value]` だけ消えます

## 完了とワークフロー状態の関係

`done` の状態を選ぶとチェックも入り、チェックを外すと状態も未完了側に戻ります。

**状態を持たないタスクには何も足しません。**チェックボックスだけのタスクが、勝手に `[status:: …]` を生やすことはありません。

## 語彙(取りうる値)を変える

`status` / `priority` の選択肢は vault の `system/settings.yaml` で決められます(アプリのコードには埋まっていません)。書かなければ既定値です。

```yaml
tasks:
  status:
    - key: todo
      label: 未着手
    - key: progress
      label: 進行中
    - key: blocked
      label: ブロック
    - key: done
      label: 完了
      done: true
  priority:
    - key: low
      label: 低
    - key: high
      label: 高
```

既定は status が `todo` / `progress` / `blocked` / `done`、priority が `low` / `medium` / `high` / `urgent` です。

## ポイント

- リスト行では Tab / Shift+Tab でインデント(アウトライン操作)が効きます
- コードフェンスの中の `- [ ]` は説明とみなし、タスクとして数えません
- エージェントからは `list_tasks`(行番号つき一覧)/ `task_vocab` / `set_task`(1 行だけ書き換え)
