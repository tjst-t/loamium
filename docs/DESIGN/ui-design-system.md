# UI デザインシステム

> 2026-08-22 の全面リデザインで定めたもの。実装は `packages/ui/src/styles.css` の 1 ファイル。

## 主題

Loamium は**ローカルの Markdown ファイルが正本**で、アプリはそれを覗くレンズにすぎない。
画面の仕事は「日本語と英語が混ざった密度の高いテキストを、キーボード中心で何時間も読み書きできること」。
売り込むための画面ではなく、道具の画面として設計する。

## 3 つの規則

1. **ディスク上にそのまま存在する文字列は等幅で組む。**
   パス・ファイル名・タグ・日付 (ファイル名でもある)・行番号・ショートカット・コード。
   アプリがそれについて語る言葉 (説明・見出し・本文) は比例フォント。
   → 「どこまでがファイルの中身で、どこからがアプリの都合か」が書体で分かる。

2. **色は装飾ではなく信号。**
   - アクセント (深い青緑) = *いまここ* / リンク / 選択
   - フラグ (酸化鉄の赤) = *直すべきもの* — 壊れリンク・未保存・削除
   - それ以外はすべて紙とインク。タグにも色を付けない (ファイルの文字列だから書体で示す)

3. **派手さは 1 か所だけ。** 地層レール (下記) 以外は静かに保つ。

## 密度

道具の画面なので、余白より情報量を優先する。

| | 値 |
|---|---|
| UI の本文 | 13px / 行間 1.5 |
| ノートの本文 | 14.5px / 行間 1.7 (日本語で 45 字前後 = 680px) |
| ブロック間 | `.55em` |
| ツリー 1 行 | 24px (モバイルは 44px) |
| 間隔スケール | 3 / 6 / 10 / 14 / 20 / 26 / 36 px |

## 書体

すべて同梱する (CDN を引かない。オフラインでも初回から同じ見た目で立ち上がる)。
和文は OS の書体にフォールバックする (数 MB の和文フォントは同梱しない)。

| 役割 | 書体 | 使う場所 |
|---|---|---|
| display | **Zilla Slab** 500/600 | ワードマーク、本文の h1–h3、検索結果のノート名 |
| body / UI | **Fira Sans** 400/500 | 本文、ラベル、ボタン |
| mono | **Fira Mono** 400/500 | 規則 1 に当てはまるものすべて |

Zilla Slab は Fira Mono の骨格から作られた書体なので、3 つが同じ家系でまとまる。

## ペインの幅

左右のサイドバーは境界をドラッグして変えられる (`packages/ui/src/components/Resizer.tsx`)。

- 幅は `localStorage` に憶える。ドラッグ終了時に 1 回だけ書く
- 下限・上限でクランプする (左 180–460px / 右 200–520px)
- **ダブルクリックで既定に戻る**、矢印キーでも動く (`role="separator"`)
- つまみは幅 0 の grid 列に置き、負のマージンで境界にまたがらせる
  (掴む面積は 6px、見た目の罫線は 1px のまま)
- 縦積みになるモバイルでは出さない

## ディテール

見た目より先に、**動いてはいけないものが動かないこと**。

- 状態で出たり消えたりする要素は、枠を残して `visibility` で消す
  (例: ジャーナルカードの「今日へ」。出入りで日付の位置が動いていた)
- 重ねるもの (パレット) はグリッドの外に置く。グリッドの子だと余分な行ができて本文が縮む

## 下限として必ず満たすもの

- キーボードフォーカスが見える (`:focus-visible` にアクセントのリング)
- `prefers-reduced-motion` を尊重する (アニメーションは 120–160ms の必要最小限)
- `prefers-color-scheme: dark` に追従する
- モバイル (≤680px): タップターゲット 44px 以上、右パネルはボトムシート、既定で閉じる
