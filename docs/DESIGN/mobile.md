# モバイル UI 規約

> この文書は**新しい機能を足すときに従う規約**。実装は `packages/ui/src/` のシェルにあり、
> 機能 (`packages/features/<機能名>/ui.tsx`) 側は原則としてモバイル固有のコードを書かない。

## 3 つの区分

境界は `packages/ui/src/use-media.ts` の `BREAKPOINT` が唯一の出所 (CSS の `@media` もこの値に揃える)。

| 幅 | 名前 | 画面の作り |
|---|---|---|
| ≤ 680px | モバイル | **1 画面 1 面。** 上部バー + 本文。左 (ナビ) と右 (情報) は**ドロワーで重ねる** |
| 681–960px | タブレット | 本文 + 左サイドバー。右パネルは**既定で閉じる**、開いても幅を抑える |
| ≥ 961px | デスクトップ | 3 面 + ドラッグで幅変更 |

**縦に積まない。** 狭い画面で 3 つの面を縦に並べると、どれも中途半端な高さになり本文が読めない。

## モバイルの骨格

```
┌─────────────────────────────┐
│ ☰   ノート名        🔍  ▤   │ ← 上部バー (48px + safe-area)
├─────────────────────────────┤
│                             │
│          本文               │ ← 1 面だけ
│                             │
└─────────────────────────────┘
  ☰ → 左ドロワー (ナビ)   ▤ → 右ドロワー (情報)
```

- 上部バー: 左 = ナビを開く / 中央 = **いまどこにいるか** / 右 = 検索・情報
- ドロワー: 幅 `min(86vw, 360px)`、背景 (scrim) をタップか `Escape` で閉じる

## ドロワーが必ず守ること (`components/Drawer.tsx`)

1. 背後の画面をスクロールさせない (`body.is-drawer-open`)
2. scrim のタップと `Escape` で閉じる
3. 開いたらフォーカスを中へ、閉じたら**元の場所へ戻す**
4. `role="dialog"` / `aria-modal="true"` / `aria-label`
5. 閉じるボタンは 44px

これらはユニットテスト (`__tests__/drawer.test.tsx`) で固定してある。

## 機能を書くときの規約

- **モバイル用の分岐を機能に書かない。** 機能は `defineUiFeature` のスロット
  (`sidebarItem` / `panelSection` / `view` / `overlay` / `commands`) を宣言するだけで、
  どこに置かれるか (サイドバーかドロワーか) はシェルが決める
- **画面遷移や本文内ジャンプを起こしたら `shell.dismiss()` を呼ぶ。**
  モバイルでは自分が本文に重なっているので、そのままだと結果が見えない
  (`openNote` / `openTag` / `openSearch` はシェル側で呼んでいるので不要)
- **触れるものは 44px 以上。** 見た目を小さく保ちたいときは、`::after { inset: -10px }` で
  当たり判定だけ広げる (アウトラインの折りたたみ・目次の折りたたみがこの形)
- **物理キーボード前提の表示を出さない。** `kbd` のショートカット表記はモバイルでは隠す。
  操作の入口はキーだけにせず、必ず触れる導線も用意する (例: 検索は上部バーの虫めがね)
- **下端は `env(safe-area-inset-bottom)` を足す。** 本文・検索ページ・ドロワーの下端が対象
- **本文の文字は小さくしない** (モバイルは 15.5px / 行間 1.75)。入力欄は 16px 以上
  (iOS は 16px 未満の入力欄で自動ズームする)

## 重なりの順序 (z-index)

| 層 | z-index | 例 |
|---|---|---|
| 本文の上に貼り付くもの | 5–6 | エディタのツールバー、幅のつまみ |
| その場に出るもの | 20–40 | ツリーのメニュー、補完ポップアップ |
| 画面を覆うもの | 50–60 | 検索パレット (50) / ドロワー (60) |

## 確認の仕方

`make serve` + `make serve-ui` の後、390×844 (iPhone 相当) で:

1. 上部バーの ☰ → 左ドロワー → ノートを選ぶ → **ドロワーが閉じて本文が出る**
2. 右上の ▤ → 情報ドロワー → 目次をタップ → **閉じてその見出しへ飛ぶ**
3. `Escape` と背景タップの両方で閉じる
4. ドロワーを開いている間、背後がスクロールしない
