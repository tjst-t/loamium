## Key Design Decisions
- Token stored in .loamium/sync-credentials.json with chmod 0600 (double-set: writeFile mode + fs.chmod)
- Auth applied per-command via -c http.extraheader only on push/pull (#runWithAuth)
- configureRemote() is non-fatal in routes (PUT /api/sync/config succeeds even if git unavailable)
- Startup pull is non-fatal (caught + logged to stderr only)
- .gitignore with .loamium/ is required in vault for pull --rebase to work (audit.log untracked otherwise)
- Test helper: git branch -m master main + git symbolic-ref HEAD refs/heads/main on bare repo (env may default to 'master')
